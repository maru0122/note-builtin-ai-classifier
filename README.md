# Note Built-in AI Classifier (Experimental PoC)

note 記事の一次情報度をオンデバイス AI（Gemini Nano）で推論し、著者の運用実態をルールベース統計で即座に判定する、Manifest V3 準拠のハイブリッド型 Chrome 拡張機能です。

Chrome 内蔵 AI（Prompt API）の実装検証および、AI推論と静的解析を組み合わせた負荷分散アーキテクチャの概念実証（PoC）として設計されています。

---

## 💡 コンセプト & アーキテクチャ

本拡張機能は、AI の文脈把握力と、JavaScript による確定的なデータ集計を適材適所で使い分けるハイブリッド設計を採用しています。

1. **記事判定（オンデバイス AI 推論）**
   - 記事タイトル、見出し構造、本文冒頭（最大800文字）を Chrome 内蔵の Gemini Nano に投入。
   - 外部サーバーへの通信を一切行わず、完全ローカル環境で一次情報の有無や商材誘導リスクを判定します。
2. **著者判定（客観データ統計・ルールベース集計）**
   - note 公式 RSS フィードおよび著者ページ HTML から客観的な指標を集計。
   - AI 特有の共感フレーズに左右されず、機械的な連投ペースや相互フォロー運用、互助会マガジンへの参加をスコアリングします。

---

## 🌟 主な機能 (Features)

* **完全オンデバイス AI 推論（プライバシー保護 & ゼロレイテンシ通信）**
  外部 API（OpenAI や Gemini API 等）との通信を行わないため、API キーの設定や従量課金、外部へのデータ送信リスクがありません。
* **RSS & HTML 並行解析による著者スコアリング**
  AI に依存しない純粋な JavaScript 処理により、ボタン押下から即座に運用アカウント判定を返却します。
* **動的インジェクション & 簡易 Markdown レンダラー**
  note の SPA ルーティングを `MutationObserver` で検知し、判定ボタンと結果カードを自動挿入。結果は独自パーサーにより安全に HTML レンダリングされます。
* **Side Panel によるプロンプトカスタマイズ**
  Chrome Side Panel API を利用し、記事判定時のシステムプロンプトやユーザー指示テンプレートをブラウザ上で直接調整・保存（`chrome.storage.local`）可能です。

## 📊 判定アルゴリズム仕様

### 1. 著者判定（客観スコアリング基準）
主観を排除し、以下の客観指標の加算スコアによって厳密に色判定を行います。

| カテゴリ | 検出条件 | スコア加算 | 表示インジケーター例 |
| :--- | :--- | :--- | :--- |
| **投稿頻度** | 直近記事の平均投稿間隔 $\le$ 16時間 | **+35点** | ⏱️ 超高頻度・連投ペース |
| | 直近記事の平均投稿間隔 $\le$ 28時間 | **+15点** | ⏱️ 高頻度投稿 |
| **相互フォロー** | フォロー・フォロワー共に 500以上、かつ比率 $\ge$ 85% | **+35点** | 👥 相互フォロー運用 |
| **互助会マガジン** | 参加マガジンURLの所有者が本人以外、またはタイトルに運用意図ワードを含む | **+30点** | 📢 互助会・共同マガジン参加 |
| **タイトルの型** | 直近タイトルの 50% 以上で同一キーワードが連続使用 | **+15点** | 🏷️ タイトルの固定テンプレ化 |
| | 直近タイトルの 40% 以上が疑問形・共感煽り構文で終了 | **+15点** | ❓ 定型共感・問いかけ構文 |

* **赤 (`red`) / 50点以上**: ⚠️ 警告・AI量産 / 互助会運用アカウント
* **黄 (`yellow`) / 25点〜49点**: 👤 運用型・標準的日常ブログ（一般論中心）
* **緑 (`green`) / 24点以下**: 💎 個人・手書き・信頼性高

### 2. 記事判定（内蔵 AI レスポンス）
Gemini Nano が出力したテキストから `判定色.*?([緑黄赤])` を正規表現走査し、UI カードの外枠・背景色およびタイトルを動的に切り替えます。

## ⚙️ 動作環境 & 前提条件 (Requirements)

本拡張機能は、Chrome の実験的機能（Built-in AI / Prompt API）を利用しています。

* **Google Chrome**: 127 以降（Dev / Canary / またはフラグを有効化した Stable 版）
* **Chrome Built-in AI (Gemini Nano) の有効化**
  * 本拡張機能の記事判定を利用するには、ブラウザ側で Gemini Nano のフラグ設定およびローカルモデルのダウンロードが必要です。
  * **詳細なセットアップ手順は、以下の解説記事をご参照ください：**
    👉 [Chrome Built-in AI（Gemini Nano）セットアップガイド](https://e-shikumi-labo.com/method/chrome-builtin-ai-setup/)

> **Note**: Gemini Nano がセットアップされていない環境でも、「👤 著者情報から判定」機能（ルールベース統計解析）はそのまま動作します。

## 🚀 インストール手順 (Load Unpacked)

ビルド作業（npm build 等）は不要です。クローン後、そのまま Chrome に読み込ませて動作させることができます。

1. 本リポジトリをクローンまたは ZIP 形式でダウンロードして解凍します。
```bash
git clone https://github.com/maru0122/note-builtin-ai-classifier.git

```

2. Chrome のアドレスバーに `chrome://extensions/` を入力して開きます。
3. 右上の **「デベロッパーモード」** を ON にします。
4. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、本プロジェクトのフォルダ（`manifest.json` がある階層）を選択します。
5. note（`(https://note.com/)`）の記事ページまたは著者トップページを開くと、自動的に判定ボタンが挿入されます。
